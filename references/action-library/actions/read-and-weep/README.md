# U052 · 读书并垂耳

类别：表情与反应；待用户确认。

鼠标跟随制作提示：稳定姿态可用瞳孔小幅跟随，头部和身体低幅响应；背身时通过转头/转身表达。

所有媒体均为未重绘的动作参考。

## U052-01

[原文件](U052-01.gif) · [来源网页](https://gifdb.com/gif/cartoon-rabbit-reading-book-0asvywhpfumb3l19.html)

捧着蓝色书本阅读，眼睛与嘴巴变化，耳朵从竖起变为倾倒。

重绘注意：镜头从近景切到文字特写再到坐姿；书遮挡胸前，需要补全手与身体。
