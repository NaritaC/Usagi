# U047 · 地上平躺流鼻泡

类别：睡眠与休息；待用户确认。

鼠标跟随制作提示：闭眼睡眠期间不强行睁眼跟随；唤醒后渐进恢复。

所有媒体均为未重绘的动作参考。

## U047-01

[原文件](U047-01.gif) · [来源网页](https://tenor.com/view/chiikawa-usagi-sleep-sleeping-snore-gif-11655213321742154976)

身体横向平躺在地上，脸朝上，鼻泡和口部有细小呼吸动作。

重绘注意：适合横向躺卧剪影；无明显平地位移，不能当作躺地滑行。

## U047-02

[原文件](U047-02.gif) · [来源网页](https://usagi-project.vercel.app/)

闭眼仰躺，身体轻微呼吸起伏，旁边有睡眠符号。

重绘注意：低分辨率且另一角色贴近；重画轮廓并分离呼吸和睡眠符号。
