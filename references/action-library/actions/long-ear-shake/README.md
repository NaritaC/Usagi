# U091 · 甩动长耳朵

类别：夸张形变；待用户确认。

鼠标跟随制作提示：快速翻转或形变期间减弱/暂停瞳孔追踪，恢复稳定姿态后自然回看鼠标。

所有媒体均为未重绘的动作参考。
