# U012 · 绕着伙伴跑圈

类别：跑动与移动；待用户确认。

鼠标跟随制作提示：稳定姿态可用瞳孔小幅跟随，头部和身体低幅响应；背身时通过转头/转身表达。

所有媒体均为未重绘的动作参考。
