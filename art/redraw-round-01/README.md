这三组是白底 PNG 姿态稿，共 22 个姿态。v3 的形象与比例已获用户认可，并固定为后续制作基准；它们尚不是透明素材包或 Live2D 模型，也不作为最终动作平滑度验收。预览按姿态顺序播放，支持暂停、调速和逐帧查看。

使用内置 imagegen 生成与修订，未使用 API/CLI 备用路径。依据为用户认可的原始动图 U001、U003、U006，实际输入的原片联系表保存在 `reference-frames/`；[来源与导出信息](manifest.json)及[完整提示词](prompts.md)均随稿保存。没有使用两个 GitHub 桌宠项目中的图片。

生成器最初输出了带棋盘格的 RGB 图，而非真实透明通道；已通过图像编辑工具改成白底评审稿，未将伪透明稿当成正式素材。用户随后指出尾巴应为白色圆形毛球，侧跑中的黄色尾巴和背身缺尾巴已分别修订。

用户继续指出嘴下短弧线缺失、身体偏长。当前默认展示 v3：重新研究原始正面与背面动图后，补齐正面短弧线，并缩短躯干、减弱腰部收窄。此前保存的 `*-sheet.png` 是历史草稿，不是当前版本；中间生成结果保留在工具原始输出目录，未全部复制入库。

预览从原稿的规则格中取出姿态，按其绘制边界居中、底部对齐，以消除拼图排版造成的位置跳动；不拉伸角色、不生成中间姿态、不做透明抠图。原稿保留所有生成像素，可直接打开检查。此处对齐仅服务于形象评审，不是最终动作的接地和根运动。

用户已接受本版的脸型、圆润比例与形象表现。后续保持该版基准，继续制作真实透明通道、分层补图、Live2D 模型和动作过渡，并修整正式运动中的步态、手部衔接与细小边缘。
