# 乌萨奇形象规范

更新时间：2026-09-06。用于[首轮试绘](redraw-round-01/index.html)及后续 Codex / Live2D 美术制作。

## 用户确认的依据

以用户认可的原始动图为形象依据，首轮编号为 01、02、03、06、07、08、09；排除 04、05、10。两个 GitHub 桌宠项目用于参考实现方式，不作为本轮造型标准。原始动图的来源保留在动作库中。

本轮直接使用 [U001 跑摔弹起](../references/action-library/actions/run-bounce/README.md)、[U003 背身拍屁屁](../references/action-library/actions/butt-pat/README.md)、[U006 迎面跑](../references/action-library/actions/run-approach/README.md)。正面形象、侧面脸型和背面轮廓分别对照原片，不凭其他桌宠的画稿推断。

## 必须保持的特征

- 浅暖黄色身体、深棕色轮廓，保留原作脸型与短肢比例；不改成玩偶、写实毛发或立体渲染。
- **身体要短、圆润、饱满。** 用户指出前版躯干偏长；应缩短脸颊下面的身体段、减弱腰部收窄，形成自然连贯的圆润轮廓，不能画成上下两节的瘦长兔子。
- 长耳、粉色耳内、弧形眉、小深色眼睛及高光、粉色脸颊与短腮红线保持同一画法。背面耳朵不显示朝前的粉色耳内。
- **嘴巴下面有一条独立的短弧线。** 正面可清楚看到，和嘴之间留出小间距；不是圆点、直线、胡须或舌头的延伸。侧面根据原始素材中的角度与遮挡处理，不把正面五官画到背面。
- **尾巴是白色圆形毛球。** 白色填充，简洁绒毛边缘；侧面可被身体遮住一部分，背面应自然附着在臀部。不是黄色凸起、长尾、环形图案或打击特效。
- 正面尾巴被身体遮挡是正常的；侧面和背面不能无故消失。尾巴位置、大小和遮挡随身体转动变化，不能像贴在画布上的标记。
- 三组保持头身比例、耳长、线条、配色和五官语言。每次修稿优先更改有问题的部分，并保存新的版本。

当前 v3 已按上述反馈重绘三组，用户于 2026-09-06 明确认可：“可以，这一版已经达到我的要求”。正面、侧跑和背身三组作为后续形象基准，具体文件及 SHA-256 见[认可记录](redraw-round-01/approval.json)。分层与 Live2D 制作需保持该轮廓和特征，模型及完整动作仍需独立验收。

## 视线与 Live2D

用户已确认完整版采用 Live2D。视线跟随由眼部与头部的轻微转动、点头、侧倾共同表达；耳朵可以有自然的延迟摆动。头部与身体变形分开控制，避免整张角色图一起倾斜。

正式模型需保留可编辑画稿与模型工程，分离眼、眉、嘴、头、耳、躯干、四肢、白色毛球尾巴及道具，并补齐转动中露出的遮挡区域。本轮姿态图是画风评审稿，尚不具备这些图层或模型能力。
