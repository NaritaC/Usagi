# 把 Codex 的桌宠换成乌萨奇

九组透明动画已经制作完成，并安装到这台电脑。你现在只需要在应用里选择它。

## 现在怎么切换

1. 点击应用左下角头像，进入 **设置 → 宠物**。如果已在宠物页，直接继续下一步。
2. 点击 **刷新**。
3. 在 **自定义宠物** 中找到 **乌萨奇**，点击它旁边的 **选择**。
4. 点击 **唤醒虚拟宠物**。也可以使用个人资料菜单中的 **显示宠物**；本机显示的快捷键是 **Alt + Win + P**。

本机应用版本为 `26.901.5280.0`，窗口标题目前显示为 **ChatGPT**；这里仍指我们一直讨论的 Codex 桌面应用。上述“刷新”“选择”“唤醒虚拟宠物”名称已在本机宠物设置页核对。

首次选择后，可以试着把它左右拖动，检查是否切成相应跑姿；再观察待机、鼠标停留和工作提示时的表现。角色周围应当透明，耳朵、脚和白色尾巴应完整。

## 找不到或显示不对时

- **列表里没有乌萨奇**：先点“刷新”，必要时关闭设置页再进入；仍没有时，退出并重新打开应用。不要在任务尚未保存时强行结束进程。
- **确认应用用的是哪个目录**：点击宠物页的“打开文件夹”。其中应有 `usagi` 文件夹，里面直接放上述两个必要文件，不应再多套一层文件夹。如果使用了自定义 `CODEX_HOME`，以应用打开的目录为准。
- **宠物存在但不动**：检查系统是否开启了减少动画设置；应用会尊重该设置并显示静态首帧。平静待机本来就较慢。
- **需要恢复原来的宠物**：回到同一页面，选择内置 **Codex** 或 **Dewey**。本次安装前选中的是 Dewey。
- **需要移除本包**：先切回内置宠物、收起乌萨奇，再移除自定义宠物目录中的 `usagi` 文件夹，刷新列表即可。仓库仍保存完整成品。

换电脑时，可以把两个必要文件放到那台电脑的 `%USERPROFILE%\.codex\pets\usagi\`，然后刷新、选择。仓库还提供安装脚本，供后续维护使用；已有不同版本时会先备份到 `.codex/pet-backups/`。
