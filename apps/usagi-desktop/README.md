# 乌萨奇桌宠 · Windows 独立 App

这是一款独立运行的桌宠，无需打开 Codex，也无需登录。运行素材、窗口、行为控制和设置都包含在程序中。

## 直接使用

1. 解压 `Usagi-Desktop-0.1.0-Windows-x64.zip` 到一个普通文件夹。
2. 双击 `Usagi Desktop.exe`。请保留同一文件夹中的其他文件。
3. 乌萨奇会出现在主屏幕任务栏上方；右键角色或双击系统托盘图标打开设置。

默认宽度 **112 个界面像素**，与本机 Codex 的默认桌宠尺寸一致；设置中可在 80–144 像素间调整。程序不自动加入开机启动。

## 已实现

- 透明、无边框窗口；透明区域允许点击底下的桌面和应用。
- 默认置顶且不抢输入焦点；可关闭置顶。
- 偶尔沿当前屏幕工作区底部左右小跑，可关闭散步或暂停活动。
- 安静时看向鼠标：复用 16 个方向的角色姿态，并用方向滞回减少临界处的抖动。
- 点耳朵跳跃，点脸挥手，点身体等待；连续点击在当前动作结束后接入最后一次请求。
- 拖动时停止散步，释放后落回有效地面；丢失鼠标捕获或拖动长时间静止时恢复。
- 系统托盘提供动作、设置、恢复主屏位置和退出。
- 保存大小、散步、注视、置顶、暂停及所在屏幕的横向位置；重启后恢复。
- 显示器或工作区变化时重新定位；坐标与缩放计算使用系统的逻辑像素。

## 当前范围

这是用户选择的首个 **逐帧动画独立版本**。包含 9 组动画与 16 个注视方向；注视是切换已有完整角色图，尚不具备独立眼部与头部的 Live2D 参数控制。暂不包含 Live2D 模型工程、持棒跑、完整跑摔/变身动作链及音效；这些保留到后续阶段。

地面采用 Windows 返回的 `workArea` 底边：常规底部任务栏下会贴在任务栏上方，自动隐藏时采用系统报告的工作区。真实验证的系统、显示缩放及检查结果见 [validation.json](validation.json)。多屏、移除显示器和侧边任务栏的坐标边界有单元测试，尚未以多台实体显示器逐一实测。

## 开发和打包

需要 Node.js 24 与 npm。程序运行不需要开发工具。

```powershell
cd apps/usagi-desktop
npm ci
npm test
npm start
```

真实 Windows 交互测试还需要 PowerShell 7；它会短暂控制测试程序附近的鼠标，恢复原指针位置，使用独立配置目录。运行时请松开鼠标按钮。

```powershell
npm run test:app
npm run build:zip
```

需要避免移动实际鼠标时，可设置 `$env:USAGI_SMOKE_ISOLATED_INPUT='1'` 后运行 `npm run test:app`；该模式使用隔离的 Electron 输入和模拟全局坐标，验证记录会明确注明，与真实 Windows 指针测试区分。

输出位于 `dist/`：压缩包用于拷贝分发，`win-unpacked/Usagi Desktop.exe` 可直接启动。

## 素材与后续 Live2D

`assets/` 固定了一份现有 v2 透明素材快照，App 不依赖旧 Codex 包目录或 `art/`。`asset-manifest.json` 记录图集尺寸、原始文件指纹、透明轮廓和各行脚底锚点；跳跃保留原画的起落轨迹。`npm run prepare-assets` 默认从 App 自带 PNG/WebP 重建图标及清单；主动从原素材重新导入可用 `npm run prepare-assets -- --from-source`，要求源文件为 1536×2288 的 v2 图集。

后续 Live2D 阶段首先需要分层补绘、遮挡补全、可编辑模型和动作工程及运行导出，再将渲染器接入现有窗口与交互系统。当前逐帧版本不视为 Live2D 完整版验收通过。

设置保存在 Windows 用户应用数据目录下的 `usagi-desktop/settings.json`。旧的大尺寸设置会恢复到 Codex 对齐尺寸并保留旧配置备份。关闭设置窗口不退出桌宠；选择“退出桌宠”或托盘“退出乌萨奇”结束程序。
